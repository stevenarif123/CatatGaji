1.    - Executive Summary
   - User Personas (min 4: Admin HR, Karyawan, Pemilik Usaha, Akuntan/Finance)
   - User Stories (min 20 cerita mencakup semua persona dengan prioritas MoSCoW)
   - Deskripsi Fitur Detail (min 8 modul: Data Karyawan HRIS, Kehadiran/Absensi, Perhitungan Gaji, Slip Gaji Digital, Approval Workflow, Pelaporan Pajak/e-SPT/DJP, Dashboard & Analytics, Multi-tenant management)
   - Wireframe Descriptions (min 10 halaman/layar utama detail UI & flow)
   - Data Model (ERD lengkap min 15 entitas/tabel dengan relasi dan field detail)
   - API Specifications (min 20 endpoint dengan request/response schema)

   - Non-Functional Requirements (performa, keamanan UU PDP, skalabilitas)
   - Roadmap (min 3 fase: MVP -> v1 -> v2 dengan deliverables jelas)
   - Lampiran Formula lengkap dan contoh perhitungan
3. Struktur berkas output yang rapi dalam folder logis (misalnya `/riset`, `/prd`, `/lampiran`, serta `README.md` / index navigasi).
